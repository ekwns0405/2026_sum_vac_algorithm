# 2026_sum_vac_algorithm
방학동안 알고리즘 공부

## 1주차: Git/GitHub 기본 및 웹 동작 원리 학습
* 활동기간 : 2026년 7월 12일 일요일 20:00 ~ 23:00 (총 3시간)
* 모임 장소: Zoom회의 (온라인)
* 활동인원: 황재성, 김민규, 이다준

### 1. 실제 작업 내역
* Git/GitHub 및 버전 관리 기초 학습
    * 버전 관리 시스템(VCS) 이해: 코드의 변경 이력을 안전하게 기록하고 협업하기 위한 Git의 필요성과, 내 컴퓨터(로컬 저장소)와 외부 클라우드(원격 저장소, GitHub)의 차이점 및 역할을 학습했다.
    * 핵심 명령어 및 데이터 흐름 숙지: 작업한 코드를 저장소에 반영하기 위해 add, commit, push, pull 등의 필수 명령어가 어떻게 동작하는지 그 원리와 전체적인 사이클을 파악했다
* DFS/BFS 알고리즘 기초 이론 구축
    * 그래프 탐색의 개념 파악: 데이터가 복잡하게 연결된 구조(노드와 간선)에서, 특정 데이터를 찾기 위해 모든 정점을 체계적으로 방문하는 방법론을 학습했다.
    * DFS (깊이 우선 탐색): 한 갈래로 갈 수 있을 때까지 깊게 파고드는 DFS의 원리를 이해하고, 스택(Stack) 자료구조 및 재귀 함수를 활용한 동작 로직을 정리했다.
    * BFS (너비 우선 탐색): 시작점으로부터 인접한 노드부터 얕고 넓게 탐색하는 BFS의 원리를 파악하고, 큐(Queue) 자료구조를 활용해 최단 경로 문제 등에 어떻게 적용되는지 기초 지식을 다졌다.
